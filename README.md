⚔️ Arsenal & Balance Mod

A comprehensive Minecraft mod introducing custom armor materials, blocks, entities, powerful items, specialized tools, and a thoroughly balanced arsenal.

📌 About the Project

Arsenal & Balance is a custom Minecraft mod designed to enhance combat, progression, and world-building. By adding custom tool and armor tiers, unique items, blocks, and newly balanced entities, this mod aims to offer a refined and immersive gameplay experience without disrupting the game's core progression.

✨ Key Features

🛡️ Custom Armor & Tools: New armor materials (ModArmorMaterial) and tool tiers (ModToolMaterial) with balanced durability and unique attributes.

🧱 Blocks & Items: Expanded building and crafting possibilities with dedicated registry classes (ModBlocks, ModItems).

👾 New Entities: Custom entities (ModEntities) that bring fresh challenges and encounters to your world.

⚔️ The Arsenal: A specialized weapon and gear system (Arsenal) crafted for optimized combat.

⚖️ Fine-Tuned Balance: Meticulously adjusted configurations (Balance) to ensure smooth integration with vanilla gameplay or modpacks.

🛠️ Requirements

Before installing, make sure you have:

Minecraft (Compatible version)

Mod Loader (Forge or Fabric, depending on your build setup)

📥 Installation

Download the latest .jar release from the Releases page.

Place the .jar file into your Minecraft mods folder (e.g., %appdata%/.minecraft/mods).

Launch the game and enjoy!

📂 Project Structure

For developers looking at the source code (/mod):

ModArmorMaterial.java & ModToolMaterial.java — Tier definitions.

ModBlocks.java & ModItems.java — Registry for blocks and items.

ModEntities.java — Custom mob and entity logic.

Arsenal.java — Weaponry and combat mechanics.

Balance.java — Stat balancing and scaling logic.
